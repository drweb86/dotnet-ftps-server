# Privacy policy

Last update: 2 September 2026

**FTPS Server** by Siarhei Kuchuk

App name: FTPS Server
Developer name: Siarhei Kuchuk

Di software na local FTPS server (FTP over TLS). E no create cloud account.
Di developer no dey run any backend wey go receive your files, passwords, or usage data.

## Data wey di developer no collect

Di app no get ads, analytics, crash reporter, or tracking SDK. Di developer no collect, sell, or share personal data.

Di app no open websites or oda outside pages.

## Data wey dey store for your device

App settings (including FTPS usernames and passwords) dey only for app-private storage on di device. Dem no dey inside Android backup. If you uninstall di app, e go remove dem.

Folders na system document picker you go use take choose. Di app only share folders wey you grant. Shared files still dey for those folders; uninstall no go delete dem.

No developer server dey use.

## Network use

When di server dey run, e dey listen for your local network so di FTPS clients wey you configure fit read or write di folders wey you share, with di usernames and passwords wey you set. Dat traffic remain between your devices (and anybody for di network wey get those credentials). Di developer no be party to am.

Na you get responsibility for who fit reach di port, which folders you share, and how strong those passwords be.

Di app no send request to di developer or any update service.

## Permissions

Di app dey use only these permissions:

- **Internet** for file sharing.
- **Wi-Fi / network state** to show how to connect.
- **Notifications and foreground service** to keep transfers running when screen off.
- **Wake lock** to reduce sleep during transfers.

## Children

Di app na network file server. E no dey for children under 13.
