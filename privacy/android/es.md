# Política de privacidad

Última actualización: 2 de septiembre de 2026

**FTPS Server** by Siarhei Kuchuk

Application name: FTPS Server
Developer: Siarhei Kuchuk

El software es un servidor FTPS local (FTP sobre TLS). No crea cuentas en la nube.
El desarrollador no opera un servidor que reciba sus archivos, contraseñas o datos de uso.

## Datos que el desarrollador no recopila

La aplicación no incluye anuncios, analítica, informes de fallos ni SDK de seguimiento. El desarrollador no recopila, vende ni comparte datos personales.

La aplicación no abre sitios web ni otras páginas externas.

## Datos almacenados en su dispositivo

La configuración de la aplicación (incluidos nombres de usuario y contraseñas de FTPS) se guarda solo en el almacenamiento privado de la aplicación en el dispositivo. No se incluye en la copia de seguridad de Android. Al desinstalar la aplicación se elimina.

Las carpetas se eligen con el selector de documentos del sistema. La aplicación comparte solo las carpetas para las que usted concede permiso. Los archivos compartidos permanecen en esas carpetas; desinstalar la aplicación no los elimina.

No se usa ningún servidor del desarrollador.

## Uso de la red

Mientras el servidor está en ejecución, escucha en su red local para que los clientes FTPS que configure puedan leer o escribir en las carpetas compartidas, con los nombres de usuario y contraseñas que usted defina. Ese tráfico permanece entre sus dispositivos (y cualquiera en la red que tenga esas credenciales). El desarrollador no participa.

Usted es responsable de quién puede alcanzar el puerto, de qué carpetas comparte y de lo robustas que sean esas contraseñas.

La aplicación no envía solicitudes al desarrollador ni a ningún servicio de actualizaciones.

## Permisos

La aplicación usa solo los siguientes permisos:

- **Internet** para compartir archivos.
- **Estado de Wi-Fi / red** para mostrar cómo conectarse.
- **Notificaciones y un servicio en primer plano** para mantener las transferencias con la pantalla apagada.
- **Wake lock** para reducir las suspensiones durante las transferencias.

## Niños

La aplicación es un servidor de archivos en red. No está dirigida a menores de 13 años.
