# 개인정보 처리방침

최종 업데이트: 2026년 9월 2일

**FTPS Server** by Siarhei Kuchuk

Application name: FTPS Server
Developer: Siarhei Kuchuk

본 소프트웨어는 로컬 FTPS(TLS 위의 FTP) 서버입니다. 클라우드 계정을 만들지 않습니다.
개발자는 파일, 비밀번호, 사용 데이터를 받는 백엔드를 운영하지 않습니다.

## 개발자가 수집하지 않는 데이터

앱에는 광고, 분석, 오류 보고, 추적 SDK가 없습니다. 개발자는 개인정보를 수집, 판매, 공유하지 않습니다.

앱은 웹사이트나 기타 외부 페이지를 열지 않습니다.

## 기기에 저장되는 데이터

앱 설정(FTPS 사용자 이름과 비밀번호 포함)은 기기의 앱 전용 저장소에만 보관됩니다. Android 백업에 포함되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

폴더는 시스템 문서 선택기로 고릅니다. 앱은 권한을 부여한 폴더만 공유합니다. 공유 파일은 해당 폴더에 남으며, 앱을 삭제해도 지워지지 않습니다.

개발자 서버는 사용하지 않습니다.

## 네트워크 사용

서버가 실행 중일 때 로컬 네트워크에서 수신 대기하여, 구성한 FTPS 클라이언트가 설정한 사용자 이름과 비밀번호로 공유 폴더를 읽거나 쓸 수 있습니다. 해당 트래픽은 기기 사이(그리고 그 자격 증명을 가진 네트워크상의 누구든지)에만 머무릅니다. 개발자는 당사자가 아닙니다.

포트에 누가 접근할 수 있는지, 어떤 폴더를 공유하는지, 비밀번호가 얼마나 강한지는 사용자의 책임입니다.

앱은 개발자나 업데이트 서비스에 요청을 보내지 않습니다.

## 권한

앱은 다음 권한만 사용합니다.

- **인터넷** — 파일 공유.
- **Wi-Fi / 네트워크 상태** — 연결 방법 표시.
- **알림 및 포그라운드 서비스** — 화면이 꺼져도 전송 유지.
- **Wake lock** — 전송 중 절전 감소.

## 아동

본 앱은 네트워크 파일 서버이며 13세 미만 아동을 대상으로 하지 않습니다.
