# Политика конфиденциальности

Последнее обновление: 2 сентября 2026 г.

**FTPS Server** by Siarhei Kuchuk

Application name: FTPS Server
Developer: Siarhei Kuchuk

Программа — локальный сервер FTPS (FTP поверх TLS). Она не создаёт облачные учётные записи.
Разработчик не использует сервер, который получал бы ваши файлы, пароли или данные об использовании.

## Данные, которые разработчик не собирает

В приложении нет рекламы, аналитики, отправки отчётов о сбоях и SDK отслеживания. Разработчик не собирает, не продаёт и не передаёт персональные данные.

Приложение не открывает сайты и другие внешние страницы.

## Данные на устройстве

Настройки приложения (включая имена пользователей и пароли FTPS) хранятся только в закрытом хранилище приложения на устройстве. Они не входят в резервное копирование Android. Удаление приложения удаляет и их.

Папки выбираются системным выбором документов. Приложение открывает доступ только к папкам, которые вы разрешили. Общие файлы остаются в этих папках; удаление приложения их не удаляет.

Сервер разработчика не используется.

## Использование сети

Пока сервер запущен, он слушает вашу локальную сеть, чтобы настроенные вами FTPS-клиенты могли читать или записывать файлы в общие папки с заданными вами именами и паролями. Этот трафик остаётся между вашими устройствами (и любым в сети, у кого есть эти учётные данные). Разработчик в нём не участвует.

Вы отвечаете за то, кто может достучаться до порта, какие папки вы открываете и насколько стойки эти пароли.

Приложение не отправляет запросы разработчику и никакой службе обновлений.

## Разрешения

Приложение использует только следующие разрешения:

- **Интернет** — для обмена файлами.
- **Состояние Wi-Fi / сети** — чтобы показать, как подключиться.
- **Уведомления и служба переднего плана** — чтобы передачи продолжались при выключенном экране.
- **Wake lock** — чтобы устройство реже засыпало во время передач.

## Дети

Приложение — сетевой файловый сервер. Оно не предназначено для детей младше 13 лет.
