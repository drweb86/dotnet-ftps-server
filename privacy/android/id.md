# Kebijakan privasi

Terakhir diperbarui: 2 September 2026

Perangkat lunak ini adalah server FTPS lokal (FTP melalui TLS). Aplikasi tidak membuat akun cloud.
Pengembang tidak mengoperasikan backend yang menerima berkas, kata sandi, atau data penggunaan Anda.

## Data yang tidak dikumpulkan pengembang

Aplikasi tidak berisi iklan, analitik, pelaporan kerusakan, atau SDK pelacakan. Pengembang tidak mengumpulkan, menjual, atau membagikan data pribadi.

Aplikasi tidak membuka situs web atau halaman eksternal lain.

## Data yang disimpan di perangkat

Pengaturan aplikasi (termasuk nama pengguna dan kata sandi FTPS) hanya disimpan di penyimpanan pribadi aplikasi di perangkat. Pengaturan itu tidak termasuk dalam cadangan Android. Mencopot pemasangan aplikasi akan menghapusnya.

Folder dipilih dengan pemilih dokumen sistem. Aplikasi hanya membagikan folder yang Anda izinkan. Berkas yang dibagikan tetap di folder tersebut; mencopot aplikasi tidak menghapusnya.

Tidak digunakan server pengembang.

## Penggunaan jaringan

Saat server berjalan, ia mendengarkan di jaringan lokal agar klien FTPS yang Anda atur dapat membaca atau menulis folder yang dibagikan, dengan nama pengguna dan kata sandi yang Anda tetapkan. Lalu lintas itu tetap di antara perangkat Anda (dan siapa pun di jaringan yang memiliki kredensial tersebut). Pengembang bukan pihak di dalamnya.

Anda bertanggung jawab atas siapa yang dapat mencapai port, folder mana yang Anda bagikan, dan seberapa kuat kata sandi itu.

Aplikasi tidak mengirim permintaan ke pengembang atau ke layanan pembaruan mana pun.

## Izin

Aplikasi hanya menggunakan izin berikut:

- **Internet** untuk berbagi berkas.
- **Status Wi-Fi / jaringan** untuk menampilkan cara terhubung.
- **Notifikasi dan layanan latar depan** agar transfer tetap berjalan saat layar mati.
- **Wake lock** untuk mengurangi tidur selama transfer.

## Anak-anak

Aplikasi ini adalah server berkas jaringan. Tidak ditujukan kepada anak di bawah 13 tahun.

## Kontak

Pertanyaan tentang aplikasi Android ini dapat dikirim melalui halaman toko yang Anda gunakan untuk memasangnya.
