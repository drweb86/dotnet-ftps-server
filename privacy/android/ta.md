# தனியுரிமைக் கொள்கை

கடைசியாக புதுப்பிக்கப்பட்டது: 2 செப்டம்பர் 2026

**FTPS Server** by Siarhei Kuchuk

Application name: FTPS Server
Developer: Siarhei Kuchuk

இந்த மென்பொருள் உள்ளூர் FTPS (TLS மீது FTP) சேவையகம். இது மேகக் கணக்குகளை உருவாக்காது.
உங்கள் கோப்புகள், கடவுச்சொற்கள் அல்லது பயன்பாட்டுத் தரவைப் பெறும் பின்புலத்தை உருவாக்குநர் இயக்கவில்லை.

## உருவாக்குநர் சேகரிக்காத தரவு

செயலியில் விளம்பரங்கள், பகுப்பாய்வு, செயலிழப்பு அறிக்கை அல்லது கண்காணிப்பு SDK இல்லை. உருவாக்குநர் தனிப்பட்ட தரவைச் சேகரிக்கவோ விற்கவோ பகிரவோ மாட்டார்.

செயலி இணையதளங்கள் அல்லது பிற வெளிப்புறப் பக்கங்களைத் திறக்காது.

## உங்கள் சாதனத்தில் சேமிக்கப்படும் தரவு

செயலி அமைப்புகள் (FTPS பயனர் பெயர்கள் மற்றும் கடவுச்சொற்கள் உட்பட) சாதனத்தில் செயலியின் தனிச் சேமிப்பில் மட்டுமே இருக்கும். அவை Android காப்புப்பிரதியில் சேர்க்கப்படாது. செயலியை நீக்கினால் அவை அகலும்.

கோப்புறைகள் கணினி ஆவணத் தேர்வியால் தேர்ந்தெடுக்கப்படுகின்றன. நீங்கள் அனுமதிக்கும் கோப்புறைகளை மட்டுமே செயலி பகிரும். பகிரப்பட்ட கோப்புகள் அந்தக் கோப்புறைகளிலேயே இருக்கும்; செயலியை நீக்கினால் அவை அழியாது.

உருவாக்குநர் சேவையகம் பயன்படுத்தப்படுவதில்லை.

## பிணையப் பயன்பாடு

சேவையகம் இயங்கும்போது உங்கள் உள்ளூர் பிணையத்தில் கேட்கிறது, நீங்கள் அமைத்த FTPS வாடிக்கையாளர்கள் நீங்கள் அமைத்த பயனர் பெயர் மற்றும் கடவுச்சொல்லால் பகிர்ந்த கோப்புறைகளைப் படிக்கவோ எழுதவோ முடியும். அந்தப் போக்குவரத்து உங்கள் சாதனங்களிடையே இருக்கும் (அந்தச் சான்றுகளைக் கொண்ட பிணையத்திலுள்ள எவரும்). உருவாக்குநர் அதில் பங்கேற்பதில்லை.

துறைமுகத்தை யார் அடையலாம், எந்தக் கோப்புறைகளைப் பகிர்கிறீர்கள், கடவுச்சொற்கள் எவ்வளவு வலிமையானவை என்பதற்கு நீங்கள் பொறுப்பு.

செயலி உருவாக்குநருக்கோ எந்தப் புதுப்பிப்புச் சேவைக்கோ கோரிக்கைகளை அனுப்பாது.

## அனுமதிகள்

செயலி இந்த அனுமதிகளை மட்டுமே பயன்படுத்துகிறது:

- கோப்பு பகிர்வுக்கு **இணையம்**.
- எவ்வாறு இணைப்பது என்பதைக் காட்ட **Wi-Fi / பிணைய நிலை**.
- திரை அணைந்திருக்கும்போதும் பரிமாற்றத்தைத் தொடர **அறிவிப்புகள் மற்றும் முன்புறச் சேவை**.
- பரிமாற்றத்தின் போது உறக்கத்தைக் குறைக்க **Wake lock**.

## குழந்தைகள்

இச்செயலி பிணையக் கோப்புச் சேவையகம். 13 வயதுக்குட்பட்ட குழந்தைகளுக்கானதல்ல.
