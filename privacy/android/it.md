# Informativa sulla privacy

Ultimo aggiornamento: 2 settembre 2026

**FTPS Server** by Siarhei Kuchuk

Application name: FTPS Server
Developer: Siarhei Kuchuk

Il software è un server FTPS locale (FTP su TLS). Non crea account cloud.
Lo sviluppatore non gestisce un backend che riceva i tuoi file, le password o i dati di utilizzo.

## Dati che lo sviluppatore non raccoglie

L’app non include pubblicità, analisi, segnalazioni di arresti anomali né SDK di tracciamento. Lo sviluppatore non raccoglie, vende né condivide dati personali.

L’app non apre siti web né altre pagine esterne.

## Dati memorizzati sul dispositivo

Le impostazioni dell’applicazione (inclusi nomi utente e password FTPS) sono salvate solo nell’archivio privato dell’app sul dispositivo. Non sono incluse nel backup di Android. La disinstallazione dell’app le rimuove.

Le cartelle si scelgono con il selettore di documenti di sistema. L’app condivide solo le cartelle per le quali concedi l’accesso. I file condivisi restano in quelle cartelle; la disinstallazione dell’app non li elimina.

Non viene usato alcun server dello sviluppatore.

## Uso della rete

Mentre il server è in esecuzione, è in ascolto sulla rete locale in modo che i client FTPS che configuri possano leggere o scrivere nelle cartelle condivise, con i nomi utente e le password che imposti. Quel traffico resta tra i tuoi dispositivi (e chiunque sulla rete abbia quelle credenziali). Lo sviluppatore non ne è parte.

Sei responsabile di chi può raggiungere la porta, di quali cartelle condividi e di quanto siano robuste quelle password.

L’app non invia richieste allo sviluppatore né ad alcun servizio di aggiornamento.

## Autorizzazioni

L’app usa solo le seguenti autorizzazioni:

- **Internet** per la condivisione di file.
- **Stato Wi-Fi / rete** per mostrare come connettersi.
- **Notifiche e un servizio in primo piano** per continuare i trasferimenti a schermo spento.
- **Wake lock** per ridurre le sospensioni durante i trasferimenti.

## Minori

L’app è un server di file in rete. Non è destinata a minori di 13 anni.
