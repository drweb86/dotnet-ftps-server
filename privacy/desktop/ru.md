# Политика конфиденциальности

Последнее обновление: 13 сентября 2026 г.


**FTPS Server** by Siarhei Kuchuk

Название приложения: FTPS Server
Имя разработчика: Siarhei Kuchuk

Программа — локальный сервер FTPS (FTP поверх TLS). Она не создаёт облачные учётные записи.
Разработчик не использует сервер, который получал бы ваши файлы, пароли или данные об использовании.

## Данные, которые разработчик не собирает

В приложении нет рекламы, аналитики, отправки отчётов о сбоях и SDK отслеживания. Разработчик не собирает, не продаёт и не передаёт персональные данные.

## Данные на компьютере

Настройки приложения (включая имена пользователей и пароли FTPS, порт сервера, лимиты подключений и необязательный путь и пароль сертификата) хранятся только на этом компьютере:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

Если приложение создаёт самоподписанный сертификат, он хранится здесь:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

Журналы сервера могут записываться сюда:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

Эти данные не загружаются разработчику. Удаление приложения или этих папок их удаляет. Общие **файлы** остаются в выбранных вами папках; приложение не копирует их на сервер разработчика.

Папки выбираются системным выбором папок. Приложение открывает доступ только к папкам, которые вы разрешили.

Сервер разработчика не используется для хранения ваших данных.

## Использование сети

### Проверка обновлений

Приложение может запросить последний выпуск GitHub:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) получает обычный HTTPS-запрос (IP-адрес, user-agent, время). Разработчик этот трафик не получает.

### Сервер FTPS

Пока сервер запущен, он слушает вашу локальную сеть, чтобы настроенные вами FTPS-клиенты могли читать или записывать файлы в общие папки с заданными вами именами и паролями. Этот трафик остаётся между вашими устройствами (и любым в сети, у кого есть эти учётные данные). Разработчик в нём не участвует.

Вы отвечаете за то, кто может достучаться до порта, какие папки вы открываете и насколько стойки эти пароли.

### Ссылки, которые вы открываете

## Другое локальное поведение

Пока сервер запущен, приложение может просить операционную систему реже уходить в сон, чтобы передачи продолжались.
