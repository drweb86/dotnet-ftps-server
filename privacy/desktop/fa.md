# سیاست حفظ حریم خصوصی

آخرین به‌روزرسانی: ۱۳ سپتامبر ۲۰۲۶


**FTPS Server** by Siarhei Kuchuk

نام برنامه: FTPS Server
نام توسعه‌دهنده: Siarhei Kuchuk

نرم‌افزار یک کارساز FTPS محلی (FTP روی TLS) است. حساب ابری نمی‌سازد.
توسعه‌دهنده پشتیبان‌سروری که پرونده‌ها، گذرواژه‌ها یا داده‌های استفاده شما را دریافت کند اداره نمی‌کند.

## داده‌هایی که توسعه‌دهنده جمع نمی‌کند

برنامه تبلیغات، تحلیل، گزارش فروپاشی یا SDK ردیابی ندارد. توسعه‌دهنده داده شخصی را جمع، فروش یا هم‌رسانی نمی‌کند.

## داده‌های ذخیره‌شده روی رایانه شما

تنظیمات برنامه (شامل نام‌های کاربری و گذرواژه‌های FTPS، درگاه کارساز، محدودیت اتصال، و مسیر و گذرواژه اختیاری گواهی) فقط روی این رایانه ذخیره می‌شود:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

اگر برنامه گواهی خودامضا بسازد، اینجا ذخیره می‌شود:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

گزارش‌های کارساز ممکن است اینجا نوشته شوند:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

این مقادیر به توسعه‌دهنده بارگذاری نمی‌شوند. حذف برنامه یا این پوشه‌ها آن‌ها را پاک می‌کند. **پرونده‌های** هم‌رسانی‌شده در پوشه‌هایی که برگزیدید می‌مانند؛ برنامه آن‌ها را به کارساز توسعه‌دهنده رونوشت نمی‌کند.

پوشه‌ها با انتخابگر پوشه سامانه برگزیده می‌شوند. برنامه فقط پوشه‌هایی را هم‌رسانی می‌کند که اجازه دهید.

هیچ کارساز توسعه‌دهنده‌ای برای ذخیره داده‌های شما استفاده نمی‌شود.

## استفاده از شبکه

### بررسی به‌روزرسانی

برنامه ممکن است آخرین انتشار GitHub را درخواست کند:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (مایکروسافت) یک درخواست HTTPS عادی (نشانی IP، عامل کاربر، زمان) دریافت می‌کند. توسعه‌دهنده آن ترافیک را دریافت نمی‌کند.

### کارساز FTPS

تا وقتی کارساز در حال اجرا است، روی شبکه محلی شما گوش می‌دهد تا مشتری‌های FTPS که پیکربندی می‌کنید بتوانند پوشه‌های هم‌رسانی‌شده را با نام کاربری و گذرواژه‌ای که تعیین کرده‌اید بخوانند یا بنویسند. آن ترافیک میان دستگاه‌های شما (و هر کس در شبکه که آن اعتبارنامه‌ها را دارد) می‌ماند. توسعه‌دهنده طرف آن نیست.

شما مسئولید چه کسی به درگاه برسد، کدام پوشه‌ها را هم‌رسانی کنید و گذرواژه‌ها چقدر قوی باشند.
