# นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 13 กันยายน 2026


**FTPS Server** by Siarhei Kuchuk

ชื่อแอปพลิเคชัน: FTPS Server
ชื่อผู้พัฒนา: Siarhei Kuchuk

ซอฟต์แวร์เป็นเซิร์ฟเวอร์ FTPS ในเครื่อง (FTP บน TLS) ไม่สร้างบัญชีคลาวด์
ผู้พัฒนาไม่ได้ดำเนินแบ็กเอนด์ที่รับไฟล์ รหัสผ่าน หรือข้อมูลการใช้งานของคุณ

## ข้อมูลที่ผู้พัฒนาไม่เก็บ

แอปไม่มีโฆษณา การวิเคราะห์ ตัวรายงานข้อขัดข้อง หรือ SDK ติดตาม ผู้พัฒนาไม่เก็บ ขาย หรือแชร์ข้อมูลส่วนบุคคล

## ข้อมูลที่เก็บในคอมพิวเตอร์ของคุณ

การตั้งค่าแอปพลิเคชัน (รวมชื่อผู้ใช้และรหัสผ่าน FTPS พอร์ตเซิร์ฟเวอร์ ขีดจำกัดการเชื่อมต่อ และเส้นทางกับรหัสผ่านใบรับรองที่เป็นทางเลือก) ถูกเก็บไว้ในคอมพิวเตอร์เครื่องนี้เท่านั้น:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

หากแอปสร้างใบรับรองที่ลงนามเอง จะถูกเก็บที่นี่:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

บันทึกเซิร์ฟเวอร์อาจถูกเขียนที่นี่:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

ค่าเหล่านั้นไม่ถูกอัปโหลดไปยังผู้พัฒนา การลบแอปหรือโฟลเดอร์เหล่านั้นจะลบข้อมูลนั้น **ไฟล์** ที่แชร์ยังอยู่ในโฟลเดอร์ที่คุณเลือก แอปไม่ได้คัดลอกไปยังเซิร์ฟเวอร์ของผู้พัฒนา

โฟลเดอร์ถูกเลือกด้วยตัวเลือกโฟลเดอร์ของระบบ แอปแชร์เฉพาะโฟลเดอร์ที่คุณอนุญาต

ไม่ใช้เซิร์ฟเวอร์ของผู้พัฒนาเพื่อเก็บข้อมูลของคุณ

## การใช้เครือข่าย

### การตรวจการอัปเดต

แอปอาจขอรุ่นล่าสุดบน GitHub:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) ได้รับคำขอ HTTPS ปกติ (ที่อยู่ IP, user-agent, เวลา) ผู้พัฒนาไม่ได้รับทราฟฟิกนั้น

### เซิร์ฟเวอร์ FTPS

ขณะที่เซิร์ฟเวอร์ทำงาน จะฟังบนเครือข่ายท้องถิ่นของคุณ เพื่อให้ไคลเอนต์ FTPS ที่คุณตั้งค่าอ่านหรือเขียนโฟลเดอร์ที่แชร์ด้วยชื่อผู้ใช้และรหัสผ่านที่คุณกำหนด ทราฟฟิกนั้นอยู่ระหว่างอุปกรณ์ของคุณ (และใครก็ตามในเครือข่ายที่มีข้อมูลรับรองนั้น) ผู้พัฒนาไม่ได้เป็นคู่กรณี

คุณรับผิดชอบว่าใครเข้าถึงพอร์ตได้ แชร์โฟลเดอร์ใด และรหัสผ่านแข็งแรงแค่ไหน
