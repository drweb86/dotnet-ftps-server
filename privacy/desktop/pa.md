# ਪਰਾਈਵੇਸੀ ਨੀਤੀ

ਆਖਰੀ ਅੱਪਡੇਟ: 13 ਸਤੰਬਰ 2026


**FTPS Server** by Siarhei Kuchuk

ਐਪ ਦਾ ਨਾਮ: FTPS Server
ਡਿਵੈਲਪਰ ਦਾ ਨਾਮ: Siarhei Kuchuk

ਇਹ ਸਾਫਟਵੇਅਰ ਇੱਕ ਸਥਾਨਕ FTPS (TLS ਉੱਤੇ FTP) ਸਰਵਰ ਹੈ। ਇਹ ਕਲਾਉਡ ਖਾਤੇ ਨਹੀਂ ਬਣਾਉਂਦਾ।
ਡਿਵੈਲਪਰ ਅਜਿਹਾ ਬੈਕਐਂਡ ਨਹੀਂ ਚਲਾਉਂਦਾ ਜੋ ਤੁਹਾਡੀਆਂ ਫਾਈਲਾਂ, ਪਾਸਵਰਡ ਜਾਂ ਵਰਤੋਂ ਡਾਟਾ ਪ੍ਰਾਪਤ ਕਰੇ।

## ਉਹ ਡਾਟਾ ਜੋ ਡਿਵੈਲਪਰ ਇਕੱਠਾ ਨਹੀਂ ਕਰਦਾ

ਐਪ ਵਿੱਚ ਇਸ਼ਤਿਹਾਰ, ਵਿਸ਼ਲੇਸ਼ਣ, ਕਰੈਸ਼ ਰਿਪੋਰਟਰ ਜਾਂ ਟਰੈਕਿੰਗ SDK ਨਹੀਂ ਹਨ। ਡਿਵੈਲਪਰ ਨਿੱਜੀ ਡਾਟਾ ਇਕੱਠਾ, ਵੇਚਦਾ ਜਾਂ ਸਾਂਝਾ ਨਹੀਂ ਕਰਦਾ।

## ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸਟੋਰ ਡਾਟਾ

ਐਪ ਸੈਟਿੰਗਾਂ (FTPS ਯੂਜ਼ਰਨੇਮ ਅਤੇ ਪਾਸਵਰਡ, ਸਰਵਰ ਪੋਰਟ, ਕਨੈਕਸ਼ਨ ਸੀਮਾਵਾਂ, ਅਤੇ ਵਿਕਲਪਿਕ ਸਰਟੀਫਿਕੇਟ ਮਾਰਗ ਤੇ ਪਾਸਵਰਡ ਸਮੇਤ) ਸਿਰਫ਼ ਇਸ ਕੰਪਿਊਟਰ ਉੱਤੇ ਸਟੋਰ ਹੁੰਦੀਆਂ ਹਨ:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

ਜੇ ਐਪ ਖੁਦ-ਦਸਤਖਤ ਸਰਟੀਫਿਕੇਟ ਬਣਾਉਂਦੀ ਹੈ, ਤਾਂ ਇਹ ਇੱਥੇ ਸਟੋਰ ਹੁੰਦਾ ਹੈ:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

ਸਰਵਰ ਲਾਗ ਇੱਥੇ ਲਿਖੇ ਜਾ ਸਕਦੇ ਹਨ:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

ਉਹ ਮੁੱਲ ਡਿਵੈਲਪਰ ਨੂੰ ਅੱਪਲੋਡ ਨਹੀਂ ਹੁੰਦੇ। ਐਪ ਜਾਂ ਉਹ ਫੋਲਡਰ ਹਟਾਉਣ ਨਾਲ ਉਹ ਮਿਟ ਜਾਂਦੇ ਹਨ। ਸਾਂਝੀਆਂ **ਫਾਈਲਾਂ** ਤੁਹਾਡੇ ਚੁਣੇ ਫੋਲਡਰਾਂ ਵਿੱਚ ਰਹਿੰਦੀਆਂ ਹਨ; ਐਪ ਉਹਨਾਂ ਨੂੰ ਡਿਵੈਲਪਰ ਸਰਵਰ ਉੱਤੇ ਕਾਪੀ ਨਹੀਂ ਕਰਦੀ।

ਫੋਲਡਰ ਸਿਸਟਮ ਫੋਲਡਰ ਚੋਣਕਾਰ ਨਾਲ ਚੁਣੇ ਜਾਂਦੇ ਹਨ। ਐਪ ਸਿਰਫ਼ ਉਹ ਫੋਲਡਰ ਸਾਂਝੇ ਕਰਦੀ ਹੈ ਜਿਨ੍ਹਾਂ ਦੀ ਤੁਸੀਂ ਇਜਾਜ਼ਤ ਦਿੰਦੇ ਹੋ।

ਤੁਹਾਡਾ ਡਾਟਾ ਰੱਖਣ ਲਈ ਡਿਵੈਲਪਰ ਸਰਵਰ ਵਰਤਿਆ ਨਹੀਂ ਜਾਂਦਾ।

## ਨੈੱਟਵਰਕ ਵਰਤੋਂ

### ਅੱਪਡੇਟ ਜਾਂਚ

ਐਪ GitHub ਦੀ ਤਾਜ਼ਾ ਰਿਲੀਜ਼ ਮੰਗ ਸਕਦੀ ਹੈ:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) ਇੱਕ ਆਮ HTTPS ਬੇਨਤੀ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ (IP ਪਤਾ, user-agent, ਸਮਾਂ)। ਡਿਵੈਲਪਰ ਉਹ ਟ੍ਰੈਫਿਕ ਨਹੀਂ ਪ੍ਰਾਪਤ ਕਰਦਾ।

### FTPS ਸਰਵਰ

ਸਰਵਰ ਚੱਲਣ ਵੇਲੇ ਉਹ ਤੁਹਾਡੇ ਸਥਾਨਕ ਨੈੱਟਵਰਕ ਉੱਤੇ ਸੁਣਦਾ ਹੈ ਤਾਂ ਜੋ ਤੁਹਾਡੇ ਸੰਰਚਿਤ FTPS ਕਲਾਇੰਟ ਤੁਹਾਡੇ ਸਾਂਝੇ ਫੋਲਡਰ ਤੁਹਾਡੇ ਸੈੱਟ ਕੀਤੇ ਯੂਜ਼ਰਨੇਮ ਅਤੇ ਪਾਸਵਰਡ ਨਾਲ ਪੜ੍ਹ ਜਾਂ ਲਿਖ ਸਕਣ। ਉਹ ਟ੍ਰੈਫਿਕ ਤੁਹਾਡੇ ਡਿਵਾਈਸਾਂ ਵਿਚਕਾਰ ਰਹਿੰਦੀ ਹੈ (ਅਤੇ ਨੈੱਟਵਰਕ ਉੱਤੇ ਜਿਸ ਕੋਲ ਉਹ ਪ੍ਰਮਾਣ ਪੱਤਰ ਹੋਣ)। ਡਿਵੈਲਪਰ ਧਿਰ ਨਹੀਂ ਹੈ।

ਪੋਰਟ ਤੱਕ ਕੌਣ ਪਹੁੰਚ ਸਕਦਾ ਹੈ, ਕਿਹੜੇ ਫੋਲਡਰ ਤੁਸੀਂ ਸਾਂਝੇ ਕਰਦੇ ਹੋ, ਅਤੇ ਉਹ ਪਾਸਵਰਡ ਕਿੰਨੇ ਮਜ਼ਬੂਤ ਹਨ ਇਸ ਦੀ ਜ਼ਿੰਮੇਵਾਰੀ ਤੁਹਾਡੀ ਹੈ।
