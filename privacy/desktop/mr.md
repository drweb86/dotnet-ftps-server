# गोपनीयता धोरण

शेवटचे अद्यतन: १३ सप्टेंबर २०२६


**FTPS Server** by Siarhei Kuchuk

अनुप्रयोगाचे नाव: FTPS Server
डेव्हलपरचे नाव: Siarhei Kuchuk

हे सॉफ्टवेअर स्थानिक FTPS (TLS वरील FTP) सर्व्हर आहे. ते क्लाउड खाती तयार करत नाही.
डेव्हलपर तुमच्या फाइल्स, पासवर्ड किंवा वापर डेटा प्राप्त करणारा बॅकएंड चालवत नाही.

## डेव्हलपर गोळा न करणारा डेटा

अॅपमध्ये जाहिराती, विश्लेषण, क्रॅश रिपोर्टर किंवा ट्रॅकिंग SDK नाहीत. डेव्हलपर वैयक्तिक डेटा गोळा, विक्री किंवा सामायिक करत नाही.

## तुमच्या संगणकावर साठवलेला डेटा

अनुप्रयोग सेटिंग्ज (FTPS वापरकर्तानाव आणि पासवर्ड, सर्व्हर पोर्ट, कनेक्शन मर्यादा आणि पर्यायी प्रमाणपत्र मार्ग व पासवर्ड) फक्त या संगणकावर साठवल्या जातात:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

अॅप स्व-स्वाक्षरीत प्रमाणपत्र तयार केल्यास ते येथे साठवले जाते:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

सर्व्हर लॉग येथे लिहिले जाऊ शकतात:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

ही मूल्ये डेव्हलपरकडे अपलोड होत नाहीत. अॅप किंवा ते फोल्डर काढल्याने ती हटतात. सामायिक **फाइल्स** तुम्ही निवडलेल्या फोल्डरमध्ये राहतात; अॅप डेव्हलपर सर्व्हरवर कॉपी करत नाही.

फोल्डर सिस्टम फोल्डर निवडकाने निवडले जातात. अॅप फक्त तुम्ही परवानगी दिलेले फोल्डर सामायिक करते.

तुमचा डेटा ठेवण्यासाठी डेव्हलपर सर्व्हर वापरला जात नाही.

## नेटवर्क वापर

### अद्यतन तपासणी

अॅप GitHub ची नवीनतम आवृत्ती विनंती करू शकते:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) सामान्य HTTPS विनंती प्राप्त करते (IP पत्ता, user-agent, वेळ). डेव्हलपर तो रहदारी प्राप्त करत नाही.

### FTPS सर्व्हर

सर्व्हर चालू असताना तो तुमच्या स्थानिक नेटवर्कवर ऐकतो जेणेकरून तुम्ही कॉन्फिगर केलेले FTPS क्लायंट तुम्ही सेट केलेल्या वापरकर्तानाव व पासवर्डने सामायिक फोल्डर वाचू किंवा लिहू शकतील. ती रहदारी तुमच्या उपकरणांमध्ये राहते (आणि नेटवर्कवर ज्यांच्याकडे ती ओळखपत्रे आहेत). डेव्हलपर पक्ष नाही.

पोर्टवर कोण पोहोचू शकतो, कोणते फोल्डर तुम्ही सामायिक करता आणि पासवर्ड किती मजबूत आहेत याची जबाबदारी तुमची आहे.
