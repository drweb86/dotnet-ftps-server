# தனியுரிமைக் கொள்கை

கடைசியாக புதுப்பிக்கப்பட்டது: 13 செப்டம்பர் 2026


**FTPS Server** by Siarhei Kuchuk

பயன்பாட்டின் பெயர்: FTPS Server
உருவாக்குநரின் பெயர்: Siarhei Kuchuk

இந்த மென்பொருள் உள்ளூர் FTPS (TLS மீது FTP) சேவையகம். இது மேகக் கணக்குகளை உருவாக்காது.
உருவாக்குநர் உங்கள் கோப்புகள், கடவுச்சொற்கள் அல்லது பயன்பாட்டுத் தரவைப் பெறும் பின்புலத்தை இயக்குவதில்லை.

## உருவாக்குநர் சேகரிக்காத தரவு

பயன்பாட்டில் விளம்பரங்கள், பகுப்பாய்வு, செயலிழப்பு அறிக்கையாளர்கள் அல்லது கண்காணிப்பு SDK இல்லை. உருவாக்குநர் தனிப்பட்ட தரவைச் சேகரிக்கவோ விற்கவோ பகிரவோ மாட்டார்.

## உங்கள் கணினியில் சேமிக்கப்படும் தரவு

பயன்பாட்டு அமைப்புகள் (FTPS பயனர் பெயர்கள் மற்றும் கடவுச்சொற்கள், சேவையக துறைமுகம், இணைப்பு வரம்புகள், விருப்பச் சான்றிதழ் பாதை மற்றும் கடவுச்சொல் உட்பட) இந்தக் கணினியில் மட்டுமே சேமிக்கப்படும்:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

பயன்பாடு தன்வயக் கையொப்பச் சான்றிதழை உருவாக்கினால், அது இங்கு சேமிக்கப்படும்:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

சேவையகப் பதிவுகள் இங்கு எழுதப்படலாம்:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

அந்த மதிப்புகள் உருவாக்குநருக்குப் பதிவேற்றப்படுவதில்லை. பயன்பாட்டை அல்லது அந்தக் கோப்புறைகளை நீக்கினால் அவை நீக்கப்படும். பகிரப்பட்ட **கோப்புகள்** நீங்கள் தேர்ந்தெடுத்த கோப்புறைகளில் இருக்கும்; பயன்பாடு அவற்றை உருவாக்குநர் சேவையகத்திற்கு நகலெடுக்காது.

கோப்புறைகள் அமைப்பு கோப்புறைத் தேர்வியால் தேர்ந்தெடுக்கப்படுகின்றன. நீங்கள் அனுமதிக்கும் கோப்புறைகளை மட்டுமே பயன்பாடு பகிரும்.

உங்கள் தரவைச் சேமிக்க உருவாக்குநர் சேவையகம் பயன்படுத்தப்படுவதில்லை.

## பிணையப் பயன்பாடு

### புதுப்பிப்புச் சரிபார்ப்பு

பயன்பாடு GitHub இன் சமீபத்திய வெளியீட்டைக் கோரலாம்:

GitHub (Microsoft) சாதாரண HTTPS கோரிக்கையைப் பெறுகிறது (IP முகவரி, user-agent, நேரம்). உருவாக்குநர் அந்தப் போக்குவரத்தைப் பெறுவதில்லை.

### FTPS சேவையகம்

சேவையகம் இயங்கும்போது உங்கள் உள்ளூர் பிணையத்தில் கேட்கிறது, நீங்கள் அமைக்கும் FTPS வாடிக்கையாளர்கள் நீங்கள் அமைத்த பயனர் பெயர்கள் மற்றும் கடவுச்சொற்களால் பகிர்ந்த கோப்புறைகளைப் படிக்கவோ எழுதவோ முடியும். அந்தப் போக்குவரத்து உங்கள் சாதனங்களுக்கு இடையே இருக்கும் (மற்றும் பிணையத்தில் அந்தச் சான்றுகள் உள்ள எவருக்கும்). உருவாக்குநர் அதில் பங்காளி அல்ல.

துறைமுகத்தை யார் அடையலாம், எந்தக் கோப்புறைகளைப் பகிர்கிறீர்கள், அந்தக் கடவுச்சொற்கள் எவ்வளவு வலுவானவை என்பதற்கு நீங்கள் பொறுப்பு.
