# ကိုယ်ရေးအချက်အလက် မူဝါဒ

နောက်ဆုံးအပ်ဒိတ်: ၂၀၂၆ စက်တင်ဘာ ၁၃


**FTPS Server** by Siarhei Kuchuk

အက်ပ်အမည်: FTPS Server
ဖန်တီးသူအမည်: Siarhei Kuchuk

ဆော့ဖ်ဝဲသည် ဒေသခံ FTPS (TLS ပေါ်ရှိ FTP) ဆာဗာဖြစ်သည်။ ကလောက်အကောင့် မဖန်တီးပါ။
ဖန်တီးသူသည် သင့်ဖိုင်များ၊ စကားဝှက်များ သို့မဟုတ် အသုံးပြုမှုဒေတာကို လက်ခံသည့် နောက်ခံကို မလည်ပတ်ပါ။

## ဖန်တီးသူ မစုဆောင်းသော ဒေတာ

အက်ပ်တွင် ကြော်ငြာ၊ ခွဲခြမ်းစိတ်ဖြာမှု၊ ပျက်စီးမှုအစီရင်ခံသူများ သို့မဟုတ် ခြေရာခံ SDK မပါဝင်ပါ။ ဖန်တီးသူသည် ကိုယ်ရေးဒေတာကို မစုဆောင်း၊ မရောင်း၊ မမျှဝေပါ။

## သင့်ကွန်ပျူတာတွင် သိမ်းဆည်းသော ဒေတာ

အက်ပ်ဆက်တင်များ (FTPS အသုံးပြုသူအမည်နှင့် စကားဝှက်များ၊ ဆာဗာပို့တ်၊ ချိတ်ဆက်မှုကန့်သတ်ချက်များနှင့် ရွေးချယ်နိုင်သော လက်မှတ်လမ်းကြောင်းနှင့် စကားဝှက်) ကို ဤကွန်ပျူတာတွင်သာ သိမ်းဆည်းသည်:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

အက်ပ်သည် ကိုယ်တိုင်လက်မှတ်ထိုး လက်မှတ် ဖန်တီးပါက ဤနေရာတွင် သိမ်းဆည်းသည်:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

ဆာဗာမှတ်တမ်းများကို ဤနေရာတွင် ရေးသားနိုင်သည်:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

ထိုတန်ဖိုးများကို ဖန်တီးသူထံ မတင်ပါ။ အက်ပ် သို့မဟုတ် ထိုဖိုလ်ဒါများကို ဖယ်ရှားခြင်းက ၎င်းတို့ကို ဖျက်သည်။ မျှဝေထားသော **ဖိုင်များ** သင်ရွေးချယ်သော ဖိုလ်ဒါများတွင် ကျန်ရှိသည်; အက်ပ်သည် ဖန်တီးသူဆာဗာသို့ မကူးယူပါ။

ဖိုလ်ဒါများကို စနစ်ဖိုလ်ဒါရွေးချယ်ကိရိယာဖြင့် ရွေးသည်။ အက်ပ်သည် သင်ခွင့်ပြုသော ဖိုလ်ဒါများကိုသာ မျှဝေသည်။

သင့်ဒေတာကို သိမ်းရန် ဖန်တီးသူဆာဗာကို မသုံးပါ။

## ကွန်ရက်အသုံးပြုမှု

### အပ်ဒိတ်စစ်ဆေးခြင်း

အက်ပ်သည် GitHub ၏ နောက်ဆုံးထုတ်ဝေမှုကို တောင်းဆိုနိုင်သည်:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) သည် ပုံမှန် HTTPS တောင်းဆိုမှု (IP လိပ်စာ၊ user-agent၊ အချိန်) ကို လက်ခံသည်။ ဖန်တီးသူသည် ထိုအသွားအလာကို မလက်ခံပါ။

### FTPS ဆာဗာ

ဆာဗာလည်ပတ်နေစဉ် ၎င်းသည် သင့်ဒေသခံကွန်ရက်တွင် နားထောင်ပြီး သင်ပြင်ဆင်ထားသော FTPS ဖောက်သည်များက သင်သတ်မှတ်သော အသုံးပြုသူအမည်နှင့် စကားဝှက်များဖြင့် မျှဝေဖိုလ်ဒါများကို ဖတ် သို့မဟုတ် ရေးနိုင်သည်။ ထိုအသွားအလာသည် သင့်စက်များကြားတွင် ရှိသည် (နှင့် ကွန်ရက်ပေါ်တွင် ထိုအထောက်အထားများ ရှိသူ မည်သူမဆို)။ ဖန်တီးသူသည် ပါတီမဟုတ်ပါ။

ပို့တ်သို့ မည်သူရောက်နိုင်သည်၊ မည်သည့်ဖိုလ်ဒါများကို မျှဝေသည်၊ စကားဝှက်များ မည်မျှခိုင်မာသည်ကို သင်တာဝန်ယူရသည်။
