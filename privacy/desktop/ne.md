# गोपनीयता नीति

अन्तिम अद्यावधिक: १३ सेप्टेम्बर २०२६


**FTPS Server** by Siarhei Kuchuk

एपको नाम: FTPS Server
डेभलपरको नाम: Siarhei Kuchuk

यो सफ्टवेयर स्थानीय FTPS (TLS माथि FTP) सर्भर हो। यसले क्लाउड खाता बनाउँदैन।
डेभलपरले तपाईंका फाइल, पासवर्ड वा प्रयोग डेटा प्राप्त गर्ने ब्याकएन्ड सञ्चालन गर्दैन।

## डेभलपरले सङ्कलन नगर्ने डेटा

एपमा विज्ञापन, विश्लेषण, क्र्यास रिपोर्टर वा ट्र्याकिङ SDK छैनन्। डेभलपरले व्यक्तिगत डेटा सङ्कलन, बिक्री वा साझा गर्दैन।

## तपाईंको कम्प्युटरमा भण्डारण गरिएको डेटा

एप सेटिङहरू (FTPS प्रयोगकर्ता नाम र पासवर्ड, सर्भर पोर्ट, जडान सीमा, र वैकल्पिक प्रमाणपत्र पथ तथा पासवर्ड सहित) यस कम्प्युटरमा मात्र भण्डारण हुन्छन्:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

एपले स्व-हस्ताक्षरित प्रमाणपत्र बनाएमा यहाँ भण्डारण हुन्छ:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

सर्भर लगहरू यहाँ लेखिन सक्छन्:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

ती मानहरू डेभलपरलाई अपलोड हुँदैनन्। एप वा ती फोल्डर हटाउँदा मेटिन्छन्। साझा **फाइलहरू** तपाईंले रोजेका फोल्डरमा रहन्छन्; एपले डेभलपर सर्भरमा प्रतिलिपि गर्दैन।

फोल्डर प्रणाली फोल्डर चयनकर्ताबाट छानिन्छन्। एपले तपाईंले अनुमति दिएका फोल्डर मात्र साझा गर्छ।

तपाईंको डेटा राख्न डेभलपर सर्भर प्रयोग हुँदैन।

## सञ्जाल प्रयोग

### अद्यावधिक जाँच

एपले GitHub को पछिल्लो रिलिज अनुरोध गर्न सक्छ:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) सामान्य HTTPS अनुरोध प्राप्त गर्छ (IP ठेगाना, user-agent, समय)। डेभलपरले त्यो ट्राफिक प्राप्त गर्दैन।

### FTPS सर्भर

सर्भर चलिरहेका बेला यसले तपाईंको स्थानीय सञ्जालमा सुन्छ ताकि तपाईंले कन्फिगर गरेका FTPS क्लाइन्टले साझा फोल्डर तपाईंले सेट गरेका प्रयोगकर्ता नाम र पासवर्डले पढ्न वा लेख्न सकून्। त्यो ट्राफिक तपाईंका यन्त्रबीच रहन्छ (र सञ्जालमा ती प्रमाणपत्र भएका जो कोही)। डेभलपर पक्ष होइन।

पोर्टमा को पुग्न सक्छ, कुन फोल्डर साझा गर्नुहुन्छ, र पासवर्ड कति बलियो छन् भन्ने जिम्मेवारी तपाईंको हो।
