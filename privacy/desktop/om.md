# Imaammata dhuunfaa

Yeroo dhumaa haaromfame: 13 Fulbaana 2026


**FTPS Server** by Siarhei Kuchuk

Maqaa appilikeeshinii: FTPS Server
Maqaa misirroostaa: Siarhei Kuchuk

Softiweerri kun seervara FTPS naannoo (FTP TLS irratti) dha. Akkaawuntii duumessa hin uumu.
Misirroostaan bifa duubaa kan faayila, jecha icciitii, ykn deetaa fayyadama kee simatu hin hojjechisu.

## Deetaa misirroostaan hin sassaabne

Appilikeeshiniin beeksisa, xiinxala, gabaasa kufaatii, ykn SDK hordoffii hin qabu. Misirroostaan deetaa dhuunfaa hin sassaabu, hin gurguru, hin hiru.

## Deetaan kompiitara kee irratti kuufame

Sajoo appilikeeshinii (maqaa fayyadamaa fi jecha icciitii FTPS, poortii seervaraa, daangaa quunnamtii, karaa sartifikeetii filannoo fi jecha icciitii dabalataan) kompiitara kana irratti qofa kuufama:

- Windows: `%LocalAppData%\FtpsServerApp\settings.json`
- Linux: `~/.local/share/FtpsServerApp/settings.json`

Yoo appilikeeshiniin sartifikeetii ofiin mallatteesse uume, asitti kuufama:

- Windows: `%LocalAppData%\FtpsServerLibrary\Certificates`
- Linux: `~/.local/share/FtpsServerLibrary/Certificates`

Galmeewwan seervaraa asitti barreeffamuu danda'u:

- Windows: `%AppData%\ftps-server\logs`
- Linux: `~/.config/ftps-server/logs`

Gatiin kun misirroostaa bira hin olfe'amu. Appilikeeshinii ykn fooldaroota kana haquun ni haqa. **Faayiloonni** hiraman fooldara filatte keessa turu; appilikeeshiniin gara seervara misirroostaa hin waraabbitu.

Fooldaroonni filataa fooldaraa sirnaatiin filamu. Appilikeeshiniin fooldara hayyamte qofa hiru.

Deetaa kee kuufachuuf seervarri misirroostaa hin fayyadamamu.

## Fayyadama cimdaa

### Sakatta'a haaromsaa

Appilikeeshiniin maxxansa GitHub haaraa gaafachuu danda'a:

`https://api.github.com/repos/drweb86/dotnet-ftps-server/releases/latest`

GitHub (Microsoft) gaaffii HTTPS idilee (teessoo IP, user-agent, yeroo) simata. Misirroostaan trafika sana hin simatu.

### Seervara FTPS

Yeroo seervarri hojjechaa jiru, cimdaa naannoo kee irratti dhaggeeffata akka maamiltoonni FTPS qindeessite fooldara hirtee maqaa fayyadamaa fi jecha icciitii kaa'iteen dubbisan ykn barreessan. Trafikiin sun meeshaalee kee gidduutti (fi eenyuyyuu cimdaa irratti ragaa qabu) hafe. Misirroostaan qaama miti.

Eenyummaan poortii ga'uu danda'u, fooldara kam hirta, fi jechoonni icciitii hammam cimoo ta'an itti gaafatama keeti.
