<p>FTPS Server உங்கள் தொலைபேசி அல்லது டேப்லெட்டை தனிப்பட்ட பகிர்வுக்கான பாதுகாப்பான FTP சேவையகமாக்குகிறது. மேகத்திற்கு ஏற்றாமல், அதே Wi-Fi இல் உள்ள கணினிக்கு புகைப்படம், வீடியோ, ஆவணம் பகிரலாம். யார் இணைக்கலாம், எந்தக் கோப்புறை, பதிவிறக்கம் மட்டும் அல்லது மாற்றமும் என்பதை நீங்கள் தேர்வு செய்கிறீர்கள்.</p>
<p><b>மேகம் வழியில் அல்ல, உங்கள் நெட்வொர்க்கில் பகிருங்கள்</b></p>
<p>கோப்புகள் உங்கள் Android சாதனத்திலேயே இருக்கும். மற்ற சாதனம் உங்கள் நெட்வொர்க் வழியே இந்த FTP சேவையகத்தில் இணைகிறது; நகல் வேறொருவர் சேமிப்பில் இருக்காது.</p>
<ul><li>புகைப்படம், வீடியோ, ஆவணத்தை தொலைபேசியிலிருந்து PC க்கும், PC இலிருந்து தொலைபேசிக்கும் நகர்த்துங்கள்.</li><li>தனிப்பட்ட, அலுவலகக் கோப்புகளை மூன்றாம் தரப்பு மேகச் சேமிப்பிற்கு வெளியே வையுங்கள்.</li><li>வீடு, அலுவலகம், அல்லது நீங்கள் கட்டுப்படுத்தும் ஹாட்ஸ்பாட்டில் பயன்படுத்துங்கள். கிளையண்ட் அதே நெட்வொர்க்கில் இருக்க வேண்டும்: அதே Wi-Fi, அதே ஹாட்ஸ்பாட், அல்லது USB கட்டும் இணைப்பு.</li><li>திரை அணைந்திருந்தாலும் சேவையகம் இயங்கட்டும். அறிவிப்பு பரிமாற்றத்தைத் தொடரும்.</li></ul>
<p><b>யார் எந்தக் கோப்புறையைத் திறக்கலாம் என்று தேர்ந்தெடுங்கள்</b></p>
<p>ஒவ்வொரு நபருக்கும் அல்லது சாதனத்துக்கும் தனி உள்நுழைவு சேர்த்து, அது என்ன செய்யலாம் என்று கட்டுப்படுத்துங்கள்.</p>
<ul><li>ஒவ்வொரு இணைப்புக்கும் பயனர் பெயரும் கடவுச்சொல்லும் உருவாக்குங்கள்.</li><li>ஒவ்வொரு உள்நுழைவுக்கும் தனி கோப்புறை. அதனால் சாதனத்தின் மற்ற கோப்புகளைப் பார்க்க முடியாது.</li><li>முழு அணுகல், அல்லது படிக்க-மட்டும்: பதிவிறக்கலாம்; பதிவேற்ற, மறுபெயரிட, நீக்க முடியாது.</li><li>மற்ற சாதனம் இணைக்கத் தயாரானால் முகவரி, போர்ட், உள்நுழைவை நகலெடுத்து அல்லது பகிருங்கள்.</li></ul>
<p><b>மறையாக்கிய பரிமாற்றம், சாதாரண FTP அல்ல</b></p>
<p>இது FTPS சேவையகம்: TLS வழியே வெளிப்படையான FTP (AUTH TLS). மறையாக்கம் இல்லாத சாதாரண FTP பயன்படாது. கடவுச்சொல்லும் கோப்பும் பரிமாற்றத்தில் மறையாக்கப்படும்.</p>
<ul><li>உள்நுழைவு மறையாக்கமின்றி அனுப்பப்படாது. பரிமாற்றம் TLS வழியே FTP பயன்படுத்தும்.</li><li>முதல் தொடக்கம் உங்களுக்காக TLS சான்றிதழை உருவாக்கும்; கூடுதல் அமைப்பு இல்லாமல் இணைக்கலாம்.</li><li>ஏற்கனவே சான்றிதழ் இருந்தால் அதையே பயன்படுத்தலாம்.</li><li>செயலியின் சான்றிதழ் கைரேகையை கிளையண்ட் காட்டுவதோடு ஒப்பிடுங்கள்; இந்த சாதனத்தையே அடைந்தீர்கள் என்று தெரியும்.</li><li>ஆங்கில அகரத்தில் இல்லாத எழுத்து உட்பட, உங்கள் மொழிக் கோப்புப் பெயர் காக்கப்படும்.</li></ul>
<p><b>சேவையகம் என்ன செய்கிறது பாருங்கள்</b></p>
<ul><li>கிளையண்டில் உள்ளிட முகவரியையும் போர்ட்டையும் செயலி காட்டும்.</li><li>ஒவ்வொரு உள்நுழைவும் கோப்புறை மற்றும் படிக்க-மட்டும் அல்லது முழு அணுகலுடன் பட்டியலாகும்.</li><li>தோல்வியின் காரணத்தைக் காண பதிவு இணைப்பைக் காட்டும்.</li><li>போர்ட் மற்றும் ஒரே நேர அதிகபட்ச கிளையண்ட் எண்ணை நீங்கள் தேர்வு செய்கிறீர்கள்.</li></ul>
<p><b>நான்கு படிகளில் FTP சேவையகத்தைத் தொடங்குங்கள்</b></p>
<p>1. பயனர் பெயர், கடவுச்சொல்லுடன் பயனரைச் சேருங்கள்.<br>2. அந்தப் பயனர் திறக்க அனுமதிக்கப்பட்ட கோப்புறையைத் தேர்ந்தெடுங்கள்.<br>3. படிக்க-மட்டும் அல்லது முழு அணுகல் தேர்ந்தெடுங்கள்.<br>4. மற்ற சாதனத்தில் FTPS கிளையண்டைத் திறந்து, வெளிப்படையான TLS (AUTH TLS) இயக்கி, முகவரி, போர்ட், உள்நுழைவை இடுங்கள்.</p>
<p><b>இணைக்கக்கூடிய கிளையண்டுகள்</b></p>
<p>வெளிப்படையான FTPS ஆதரிக்கும் எந்த கிளையண்டும் இயங்கும். எடுத்துக்காட்டு: Windows இல் FileZilla, WinSCP; Linux இல் FileZilla; Mac இல் Cyberduck அல்லது FileZilla; வேறு தொலைபேசியில் FTPS கிளையண்ட்.</p>
<p><b>வழக்கமான பயன்பாடுகள்</b></p>
<ul><li>அதே Wi-Fi இல் தொலைபேசிக்கும் மடிக்கணினிக்கும் இடையே கோப்பு நகலெடுங்கள்.</li><li>டெஸ்க்டாப் கோப்பு மேலாளரில் தொலைபேசிக் கோப்பைத் திறங்கள்.</li><li>பதிவிறக்கம் மட்டும் வேண்டுமென்றால் படிக்க-மட்டும் உள்நுழைவைக் கொடுங்கள்.</li></ul>
<p><b>இந்த FTP சேவையகம் எதுவல்ல</b></p>
<p>உருவாக்குநருக்கோ மேகச் சேவைக்கோ கோப்பை ஏற்றாது. பொதுக் கோப்பு வழங்கி அல்ல. நம்பும் நெட்வொர்க்கில் பயன்படுத்துங்கள்: வீடு அல்லது அலுவலக Wi-Fi.</p>
<p>FTPS Server திறந்த மூலம் (CC0-1.0), விளம்பரம் இல்லை.</p>
