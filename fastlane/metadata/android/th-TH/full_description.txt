<p>FTPS Server เปลี่ยนโทรศัพท์หรือแท็บเล็ตของคุณให้เป็นเซิร์ฟเวอร์ FTP ที่ปลอดภัยสำหรับแชร์ไฟล์แบบส่วนตัว แชร์รูปภาพ วิดีโอ และเอกสารกับคอมพิวเตอร์บน Wi-Fi เดียวกัน โดยไม่ต้องอัปโหลดขึ้นคลาวด์ คุณเลือกได้ว่าใครเชื่อมต่อได้ เปิดโฟลเดอร์ใดได้ และดาวน์โหลดไฟล์ได้อย่างเดียวหรือแก้ไขไฟล์ได้ด้วย</p>
<p><b>แชร์ไฟล์บนเครือข่ายของคุณ ไม่ใช่ผ่านคลาวด์</b></p>
<p>ไฟล์อยู่บนอุปกรณ์ Android ของคุณ อุปกรณ์อีกเครื่องเชื่อมต่อกับเซิร์ฟเวอร์ FTP นี้ผ่านเครือข่ายของคุณเอง ดังนั้นสำเนาจึงไม่ไปอยู่บนที่เก็บของคนอื่น</p>
<ul><li>ย้ายรูปภาพ วิดีโอ และเอกสารจากโทรศัพท์ไปยัง PC หรือจาก PC มาที่โทรศัพท์</li><li>เก็บไฟล์ส่วนตัวและไฟล์งานไว้ไม่ให้อยู่บนที่เก็บคลาวด์ของบุคคลที่สาม</li><li>ใช้ที่บ้าน ที่ทำงาน หรือบนฮอตสปอตที่คุณควบคุม ไคลเอ็นต์ต้องอยู่บนเครือข่ายเดียวกัน: Wi-Fi เดียวกัน หรือฮอตสปอตเดียวกัน หรือลิงก์การแชร์เน็ตผ่าน USB</li><li>ปิดหน้าจอแล้วเซิร์ฟเวอร์ยังทำงานต่อได้ การแจ้งเตือนช่วยให้การถ่ายโอนดำเนินต่อไป</li></ul>
<p><b>เลือกได้ว่าใครเปิดโฟลเดอร์ใด</b></p>
<p>เพิ่มล็อกอินแยกสำหรับแต่ละคนหรือแต่ละอุปกรณ์ และจำกัดว่าล็อกอินนั้นทำอะไรได้</p>
<ul><li>สร้างชื่อผู้ใช้และรหัสผ่านสำหรับทุกการเชื่อมต่อ</li><li>ให้แต่ละล็อกอินมีโฟลเดอร์ของตัวเอง ล็อกอินนั้นเรียกดูไฟล์ที่เหลือบนอุปกรณ์ของคุณไม่ได้</li><li>ให้การเข้าถึงแบบเต็ม หรือล็อกอินแบบอ่านอย่างเดียวที่ดาวน์โหลดไฟล์ได้ แต่อัปโหลด เปลี่ยนชื่อ หรือลบไม่ได้</li><li>คัดลอกหรือแชร์ที่อยู่ พอร์ต และล็อกอิน เมื่ออุปกรณ์อีกเครื่องพร้อมเชื่อมต่อ</li></ul>
<p><b>การถ่ายโอนที่เข้ารหัส ไม่ใช่ FTP แบบข้อความธรรมดา</b></p>
<p>นี่คือเซิร์ฟเวอร์ FTPS: FTP over TLS แบบชัดแจ้ง (AUTH TLS) ไม่ใช้ FTP ธรรมดาที่ไม่มีการเข้ารหัส รหัสผ่านและไฟล์ถูกเข้ารหัสขณะข้ามเครือข่าย</p>
<ul><li>ล็อกอินไม่ได้ถูกส่งแบบข้อความธรรมดา การถ่ายโอนใช้ FTP over TLS</li><li>การเริ่มครั้งแรกสร้างใบรับรอง TLS ให้คุณ จึงเชื่อมต่อได้โดยไม่ต้องตั้งค่าเพิ่ม</li><li>ถ้าคุณมีใบรับรองอยู่แล้ว สามารถใช้ใบรับรองนั้นแทนได้</li><li>เทียบลายนิ้วมือใบรับรองที่แสดงในแอปกับที่ไคลเอ็นต์แสดง เพื่อให้รู้ว่าคุณเชื่อมถึงอุปกรณ์นี้</li><li>ชื่อไฟล์ในภาษาของคุณยังอยู่ รวมถึงตัวอักษรที่ไม่อยู่ในตัวอักษรภาษาอังกฤษ</li></ul>
<p><b>ดูว่าเซิร์ฟเวอร์กำลังทำอะไร</b></p>
<ul><li>แอปแสดงที่อยู่และพอร์ตที่ต้องกรอกในไคลเอ็นต์</li><li>แต่ละล็อกอินแสดงพร้อมโฟลเดอร์ และว่าการเข้าถึงเป็นแบบอ่านอย่างเดียวหรือแบบเต็ม</li><li>บันทึกแสดงกิจกรรมการเชื่อมต่อเมื่อมีบางอย่างล้มเหลวและคุณต้องดูว่าเพราะอะไร</li><li>คุณเลือกพอร์ต และจำนวนไคลเอ็นต์ที่เชื่อมต่อพร้อมกันได้</li></ul>
<p><b>เริ่มเซิร์ฟเวอร์ FTP ในสี่ขั้นตอน</b></p>
<p>1. เพิ่มผู้ใช้ พร้อมชื่อผู้ใช้และรหัสผ่าน<br>2. เลือกโฟลเดอร์ที่ผู้ใช้คนนั้นเปิดได้<br>3. เลือกแบบอ่านอย่างเดียวหรือการเข้าถึงแบบเต็ม<br>4. บนอุปกรณ์อีกเครื่อง เปิดไคลเอ็นต์ FTPS เปิด TLS แบบชัดแจ้ง (AUTH TLS) แล้วกรอกที่อยู่ พอร์ต และล็อกอิน</p>
<p><b>ไคลเอ็นต์ที่เชื่อมต่อได้</b></p>
<p>ไคลเอ็นต์ใดก็ได้ที่รองรับ FTPS แบบชัดแจ้งสามารถใช้ได้ ตัวอย่าง: FileZilla และ WinSCP บน Windows, FileZilla บน Linux, Cyberduck หรือ FileZilla บน Mac และไคลเอ็นต์ FTPS บนโทรศัพท์อีกเครื่อง</p>
<p><b>การใช้งานทั่วไป</b></p>
<ul><li>คัดลอกไฟล์ระหว่างโทรศัพท์กับแล็ปท็อปบน Wi-Fi เดียวกัน</li><li>เปิดไฟล์ในโทรศัพท์จากตัวจัดการไฟล์บนเดสก์ท็อป</li><li>มอบล็อกอินแบบอ่านอย่างเดียวให้คนที่ควรดาวน์โหลดไฟล์ได้อย่างเดียว และไม่ทำอย่างอื่น</li></ul>
<p><b>เซิร์ฟเวอร์ FTP นี้ไม่ใช่สิ่งใด</b></p>
<p>เซิร์ฟเวอร์นี้ไม่ได้อัปโหลดไฟล์ของคุณไปยังผู้พัฒนาหรือบริการคลาวด์ และไม่ใช่โฮสต์ไฟล์สาธารณะ โปรดใช้บนเครือข่ายที่คุณไว้ใจ เช่น Wi-Fi ที่บ้านหรือที่ทำงาน</p>
<p>FTPS Server เป็นโอเพนซอร์ส (CC0-1.0) และไม่มีโฆษณา</p>
