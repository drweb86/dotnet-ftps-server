<p>FTPS Server は、スマートフォンやタブレットを、プライベートなファイル共有のための安全な FTP サーバーにします。同じ Wi-Fi 上のコンピューターと写真、動画、文書を共有でき、クラウドへアップロードする必要はありません。誰が接続できるか、どのフォルダーを開けるか、ファイルのダウンロードだけができるか、変更もできるかを選べます。</p>
<p><b>クラウド経由ではなく、自分のネットワークでファイルを共有</b></p>
<p>ファイルはお使いの Android 端末に残ります。もう一方の端末は、自分のネットワーク経由でこの FTP サーバーに接続するため、コピーが他人のストレージに置かれることはありません。</p>
<ul><li>写真、動画、文書をスマートフォンから PC へ、または PC からスマートフォンへ移します。</li><li>個人用と仕事用のファイルを、第三者のクラウドストレージに置かずに済みます。</li><li>自宅、オフィス、または自分で管理するホットスポットで使えます。クライアントは同じネットワーク上にある必要があります。同じ Wi-Fi、あるいは同じホットスポットか USB テザリングの接続です。</li><li>画面を消したままサーバーを動かし続けられます。通知により転送が続きます。</li></ul>
<p><b>誰がどのフォルダーを開けるかを選ぶ</b></p>
<p>人または端末ごとに別のログインを追加し、そのログインでできることを制限します。</p>
<ul><li>接続ごとにユーザー名とパスワードを作ります。</li><li>各ログインに専用のフォルダーを割り当てます。そのログインでは、端末上のほかのファイルを閲覧できません。</li><li>フルアクセスを許可するか、ファイルはダウンロードできるがアップロード、名前の変更、削除はできない読み取り専用ログインにします。</li><li>もう一方の端末が接続できる準備ができたら、アドレス、ポート、ログインをコピーまたは共有します。</li></ul>
<p><b>暗号化された転送であり、平文の FTP ではない</b></p>
<p>これは FTPS サーバーです。明示的な FTP over TLS（AUTH TLS）です。暗号化のない平文の FTP は使いません。パスワードとファイルは、ネットワークを通過する間暗号化されます。</p>
<ul><li>ログインは平文では送られません。転送には FTP over TLS を使います。</li><li>最初の起動時に TLS 証明書が作られるため、追加の設定なしで接続できます。</li><li>すでに証明書がある場合は、そちらを使うこともできます。</li><li>アプリに表示される証明書のフィンガープリントと、クライアントに表示されるものを比べ、この端末に到達したことを確認します。</li><li>お使いの言語のファイル名は保持されます。英語のアルファベットにない文字も含まれます。</li></ul>
<p><b>サーバーが何をしているかを見る</b></p>
<ul><li>アプリは、クライアントに入力するアドレスとポートを表示します。</li><li>各ログインは、フォルダーと、アクセスが読み取り専用かフルかとともに一覧されます。</li><li>問題が起きたとき、理由を確かめるためのログに接続の様子が表示されます。</li><li>ポートと、同時に接続できるクライアントの数を選べます。</li></ul>
<p><b>4つの手順で FTP サーバーを開始</b></p>
<p>1. ユーザー名とパスワードを付けてユーザーを追加します。<br>2. そのユーザーが開けるフォルダーを選びます。<br>3. 読み取り専用かフルアクセスかを選びます。<br>4. もう一方の端末で FTPS クライアントを開き、明示的 TLS（AUTH TLS）を有効にして、アドレス、ポート、ログインを入力します。</p>
<p><b>接続できるクライアント</b></p>
<p>明示的 FTPS に対応するクライアントであれば接続できます。例：Windows の FileZilla と WinSCP、Linux の FileZilla、Mac の Cyberduck または FileZilla、別のスマートフォンの FTPS クライアント。</p>
<p><b>主な使い方</b></p>
<ul><li>同じ Wi-Fi 上のスマートフォンとノートパソコンの間でファイルをコピーします。</li><li>デスクトップのファイルマネージャーから、スマートフォンのファイルを開きます。</li><li>ファイルをダウンロードするだけで、他の操作はできない相手には、読み取り専用のログインを渡します。</li></ul>
<p><b>この FTP サーバーではないもの</b></p>
<p>ファイルを開発者やクラウドサービスへアップロードすることはありません。公開のファイルホストでもありません。自宅やオフィスの Wi-Fi など、信頼できるネットワークで使ってください。</p>
<p>FTPS Server はオープンソース（CC0-1.0）で、広告はありません。</p>
