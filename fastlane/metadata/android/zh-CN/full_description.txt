<p>FTPS Server 把你的手机或平板变成用于私人文件共享的安全 FTP 服务器。与同一 Wi-Fi 上的电脑共享照片、视频和文档，无需上传到云端。你可以决定谁能连接、他们能打开哪个文件夹，以及他们只能下载文件还是也能修改这些文件。</p>
<p><b>在你的网络上共享文件，而不是通过云端</b></p>
<p>文件留在你的 Android 设备上。另一台设备通过你自己的网络连接到这台 FTP 服务器，因此副本不会留在别人的存储空间里。</p>
<ul><li>把照片、视频和文档从手机传到 PC，或从 PC 传到手机。</li><li>让个人文件和工作文件远离第三方云存储。</li><li>可在家里、办公室，或你所控制的热点上使用。客户端必须在同一网络：同一个 Wi-Fi，或同一个热点或 USB 网络共享连接。</li><li>屏幕关闭时服务器仍可继续运行。通知会让传输继续进行。</li></ul>
<p><b>选择谁可以打开哪个文件夹</b></p>
<p>为每个人或每台设备添加单独的登录，并限制该登录能做的事。</p>
<ul><li>为每个连接创建用户名和密码。</li><li>给每个登录自己的文件夹。该登录无法浏览设备上的其余文件。</li><li>允许完全访问，或使用只读登录：可以下载文件，但不能上传、重命名或删除。</li><li>另一台设备准备连接时，复制或分享地址、端口和登录信息。</li></ul>
<p><b>加密传输，而不是明文 FTP</b></p>
<p>这是一台 FTPS 服务器：显式 FTP over TLS（AUTH TLS）。不使用没有加密的明文 FTP。密码和文件在经过网络时都会被加密。</p>
<ul><li>登录信息不会以明文发送。传输使用 FTP over TLS。</li><li>首次启动会为你创建 TLS 证书，因此无需额外设置即可连接。</li><li>如果你已经有证书，可以改用那份证书。</li><li>把应用中显示的证书指纹与客户端显示的指纹对比，以确认你连接到的是这台设备。</li><li>你所用语言的文件名会被保留，包括不在英文字母表中的字母。</li></ul>
<p><b>查看服务器正在做什么</b></p>
<ul><li>应用会显示要在客户端输入的地址和端口。</li><li>每个登录都会列出其文件夹，以及访问是只读还是完全访问。</li><li>出了问题、需要查看原因时，日志会显示连接活动。</li><li>你可以选择端口，以及同时可以连接多少个客户端。</li></ul>
<p><b>分四步启动 FTP 服务器</b></p>
<p>1. 添加用户，并设置用户名和密码。<br>2. 选择允许该用户打开的文件夹。<br>3. 选择只读或完全访问。<br>4. 在另一台设备上打开 FTPS 客户端，开启显式 TLS（AUTH TLS），然后输入地址、端口和登录信息。</p>
<p><b>可以连接的客户端</b></p>
<p>任何支持显式 FTPS 的客户端都可以。例如：Windows 上的 FileZilla 和 WinSCP、Linux 上的 FileZilla、Mac 上的 Cyberduck 或 FileZilla，以及另一部手机上的 FTPS 客户端。</p>
<p><b>典型用途</b></p>
<ul><li>在同一 Wi-Fi 上的手机和笔记本电脑之间复制文件。</li><li>从桌面文件管理器打开手机上的文件。</li><li>当对方只应下载文件、不应做其他操作时，把只读登录交给对方。</li></ul>
<p><b>这个 FTP 服务器不是什么</b></p>
<p>它不会把你的文件上传给开发者或云服务。它也不是公开的文件托管。请在你信任的网络上使用，例如家里或办公室的 Wi-Fi。</p>
