FTPS Server 將你部手機或者平板變成一部用嚟私人分享檔案嘅安全 FTP 伺服器。你可以同用緊同一條 Wi-Fi 嘅電腦分享相片、影片同文件，唔使上傳去雲端。你揀邊個可以連線、佢哋開到邊個資料夾，同埋佢哋只可以下載檔案，定係亦都可以改呢啲檔案。

喺你自己嘅網絡分享檔案，唔係經雲端

檔案留喺你部 Android 裝置。另一部裝置經你自己嘅網絡連去呢部 FTP 伺服器，所以副本唔會擺喺其他人嘅儲存空間。

- 將相片、影片同文件由手機傳到 PC，或者由 PC 傳到手機。
- 個人同工作檔案唔好放到第三方雲端儲存度。
- 可以喺屋企、辦公室，或者你控制嘅熱點用。用戶端一定要喺同一個網絡：同一條 Wi-Fi，或者同一個熱點或者 USB 網絡共享連線。
- 螢幕熄咗都繼續行住部伺服器。通知會令傳輸繼續。

揀邊個可以開邊個資料夾

為每個人或者每部裝置加一個獨立登入，同埋限制呢個登入做到啲咩。

- 為每個連線建立用戶名稱同密碼。
- 畀每個登入自己嘅資料夾。呢個登入唔可以瀏覽你部裝置上嘅其他檔案。
- 可以畀完整存取，或者一個唯讀登入：可以下載檔案，但係唔可以上傳、重新命名或者刪除。
- 另一部裝置準備好連線嗰陣，複製或者分享地址、連接埠同登入資料。

加密傳輸，唔係明文 FTP

呢個係一部 FTPS 伺服器：顯式 FTP over TLS（AUTH TLS）。唔會用冇加密嘅明文 FTP。密碼同檔案行過網絡嗰陣都會加密。

- 登入資料唔會以明文傳送。傳輸用 FTP over TLS。
- 第一次啟動會為你建立 TLS 證書，所以唔使額外設定就連到。
- 如果你已經有證書，可以改用嗰張。
- 將應用程式顯示嘅證書指紋同用戶端顯示嘅指紋比較，就知道你連到嘅係呢部裝置。
- 你自己語言嘅檔案名會保留，包括唔喺英文字母表入面嘅字母。

睇下伺服器做緊咩

- 應用程式會顯示要喺用戶端輸入嘅地址同連接埠。
- 每個登入都會列出佢個資料夾，同埋存取係唯讀定係完整。
- 出錯要睇原因嗰陣，記錄會顯示連線活動。
- 你可以揀連接埠，同埋同時可以連幾多個用戶端。

四步啟動 FTP 伺服器

1. 加一個用戶，設定用戶名稱同密碼。
2. 揀呢個用戶可以開嘅資料夾。
3. 揀唯讀或者完整存取。
4. 喺另一部裝置開 FTPS 用戶端，開啟顯式 TLS（AUTH TLS），然後輸入地址、連接埠同登入資料。

可以連線嘅用戶端

任何支援顯式 FTPS 嘅用戶端都得。例如：Windows 上嘅 FileZilla 同 WinSCP、Linux 上嘅 FileZilla、Mac 上嘅 Cyberduck 或者 FileZilla，同埋另一部手機上嘅 FTPS 用戶端。

典型用途

- 喺同一條 Wi-Fi 上，手機同手提電腦之間複製檔案。
- 用桌面檔案管理員開手機入面嘅檔案。
- 如果對方只應該下載檔案、做唔到其他嘢，就畀佢一個唯讀登入。

呢個 FTP 伺服器唔係咩

佢唔會將你嘅檔案上傳畀開發者或者雲端服務。佢亦都唔係公開嘅檔案寄存。請喺你信任嘅網絡用，好似屋企或者辦公室嘅 Wi-Fi。
