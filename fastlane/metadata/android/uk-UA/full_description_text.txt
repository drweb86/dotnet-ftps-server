FTPS (FTP поверх TLS) сервер для безпечного обміну файлами між пристроями в мережі.

Можливості:

- Права користувачів - Гнучке керування операціями читання/запису
- Кореневі папки для кожного користувача - Ізольовані каталоги для кожного користувача
- Безпека шляхів - Захист від атак із обходом каталогів
- UTF-8 - Підтримка локалізованих символів
- Самопідписані сертифікати - Автоматичне створення TLS-сертифікатів або використання власних
