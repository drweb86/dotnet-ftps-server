<p>FTPS (FTP поверх TLS) сервер для безпечного обміну файлами між пристроями в мережі.</p>
<p><b>Можливості:</b></p>
<ul><li><b>Права користувачів</b> - Гнучке керування операціями читання/запису</li><li><b>Кореневі папки для кожного користувача</b> - Ізольовані каталоги для кожного користувача</li><li><b>Безпека шляхів</b> - Захист від атак із обходом каталогів</li><li><b>UTF-8</b> - Підтримка локалізованих символів</li><li><b>Самопідписані сертифікати</b> - Автоматичне створення TLS-сертифікатів або використання власних</li></ul>
