FTPS (FTP over TLS) server wey dey share file between devices for network with security.

Features:

- User Permissions - Fine-fine control for Read/Write operations
- Per-User Root Folders - Separate directories for each user
- Path Security - Protection from directory traversal attack
- UTF-8 - E dey support localized characters
- Self-Signed Certificates - Auto-generate TLS certificates or use your own
