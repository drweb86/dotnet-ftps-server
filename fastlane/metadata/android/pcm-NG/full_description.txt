<p>FTPS Server dey turn your phone or tablet to a secure FTP server for private file sharing. Share photo, video, and document with a computer for the same Wi-Fi, without uploading dem go cloud. You dey choose who fit connect, which folder dem fit open, and whether dem fit only download file or also change dem.</p>
<p><b>Share file for your network, no be through cloud</b></p>
<p>File dey stay for your Android device. The other device dey connect to this FTP server through your own network, so a copy no dey sit for another person storage.</p>
<ul><li>Move photo, video, and document from your phone go a PC, or from a PC go your phone.</li><li>Keep personal and work file comot from cloud storage wey no be yours.</li><li>Use am for house, for office, or for a hotspot wey you control. The client must dey for the same network: the same Wi-Fi, or the same hotspot or USB tethering link.</li><li>Leave the server dey run with the screen off. A notification dey keep transfer dey go.</li></ul>
<p><b>Choose who fit open which folder</b></p>
<p>Add separate login for each person or device, and limit wetin that login fit do.</p>
<ul><li>Create username and password for every connection.</li><li>Give each login im own folder. That login no fit browse the rest of the file wey dey your device.</li><li>Allow full access, or read-only login wey fit download file but no fit upload, rename, or delete.</li><li>Copy or share the address, port, and login when the other device don ready to connect.</li></ul>
<p><b>Encrypted transfer, no be plain FTP</b></p>
<p>This na FTPS server: explicit FTP over TLS (AUTH TLS). Plain FTP, wey no get encryption, no dey used. The password and the file dey encrypted as dem dey cross the network.</p>
<ul><li>Dem no dey send login without encryption. Transfer dey use FTP over TLS.</li><li>The first start dey create a TLS certificate for you, so you fit connect without extra setup.</li><li>If you already get a certificate, you fit use that one instead.</li><li>Compare the certificate fingerprint wey the app show with the one wey your client show, so you know say you reach this device.</li><li>File name for your own language dey kept, including letter wey no dey for the English alphabet.</li></ul>
<p><b>See wetin the server dey do</b></p>
<ul><li>The app dey show the address and port wey you go enter for the client.</li><li>Each login dey listed with im folder and whether access na read-only or full.</li><li>A log dey show connection activity when something fail and you need to see why.</li><li>You dey choose the port and how many client fit dey connected at once.</li></ul>
<p><b>Start the FTP server for four step</b></p>
<p>1. Add a user, with a username and a password.<br>2. Pick the folder wey that user fit open.<br>3. Choose read-only or full access.<br>4. For the other device, open an FTPS client, turn on explicit TLS (AUTH TLS), and enter the address, port, and login.</p>
<p><b>Client wey fit connect</b></p>
<p>Any client wey support explicit FTPS go work. Example: FileZilla and WinSCP for Windows, FileZilla for Linux, Cyberduck or FileZilla for Mac, and an FTPS client for another phone.</p>
<p><b>Wetin e dey useful for</b></p>
<ul><li>Copy file between a phone and a laptop for the same Wi-Fi.</li><li>Open phone file from a desktop file manager.</li><li>Give person read-only login when dem suppose download file and nothing else.</li></ul>
<p><b>Wetin this FTP server no be</b></p>
<p>E no dey upload your file go the developer or go a cloud service. E no be public file host too. Use am for a network wey you trust, like house or office Wi-Fi.</p>
