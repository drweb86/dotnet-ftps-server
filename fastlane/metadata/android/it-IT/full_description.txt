<p>Server FTPS (FTP su TLS) per la condivisione sicura di file tra dispositivi in rete.</p>
<p><b>Funzionalità:</b></p>
<ul><li><b>Autorizzazioni utente</b> - Controllo granulare sulle operazioni di lettura/scrittura</li><li><b>Cartelle radice per utente</b> - Directory isolate per ciascun utente</li><li><b>Sicurezza dei percorsi</b> - Protezione dagli attacchi di directory traversal</li><li><b>UTF-8</b> - Supporto dei caratteri localizzati</li><li><b>Certificati autofirmati</b> - Generazione automatica di certificati TLS o uso dei propri</li></ul>
