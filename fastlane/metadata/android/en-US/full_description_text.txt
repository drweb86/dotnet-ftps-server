FTPS Server turns your phone or tablet into a secure FTP server for private file sharing. Share photos, videos, and documents with a computer on the same Wi-Fi, without uploading them to a cloud. You choose who can connect, which folder they can open, and whether they can only download files or also change them.

Share files on your network, not through a cloud

Files stay on your Android device. The other device connects to this FTP server over your own network, so a copy is not sitting on someone else's storage.

- Move photos, videos, and documents from your phone to a PC, or from a PC onto your phone.
- Keep personal and work files off third-party cloud storage.
- Use it at home, in an office, or on a hotspot you control. The client has to be on the same network: the same Wi-Fi, or the same hotspot or USB tethering link.
- Leave the server running with the screen off. A notification keeps transfers going.

Choose who can open which folder

Add a separate login for each person or device, and limit what that login can do.

- Create a username and password for every connection.
- Give each login its own folder. That login cannot browse the rest of the files on your device.
- Allow full access, or a read-only login that can download files but cannot upload, rename, or delete.
- Copy or share the address, port, and logins when the other device is ready to connect.

Encrypted transfer, not plain FTP

This is an FTPS server: explicit FTP over TLS (AUTH TLS). Plain FTP, with no encryption, is not used. The password and the files are encrypted while they cross the network.

- A login is not sent in the clear. Transfers use FTP over TLS.
- The first start creates a TLS certificate for you, so you can connect without extra setup.
- If you already have a certificate, you can use that instead.
- Compare the certificate fingerprint shown in the app with the one shown by your client, so you know you reached this device.
- File names in your own language are preserved, including letters that are not in the English alphabet.

See what the server is doing

- The app shows the address and port to enter in the client.
- Each login is listed with its folder and whether access is read-only or full.
- A log shows connection activity when something fails and you need to see why.
- You choose the port and how many clients can be connected at once.

Start the FTP server in four steps

1. Add a user, with a username and a password.
2. Pick the folder that user is allowed to open.
3. Choose read-only or full access.
4. On the other device, open an FTPS client, turn on explicit TLS (AUTH TLS), and enter the address, port, and login.

Clients that can connect

Any client that supports explicit FTPS works. Examples: FileZilla and WinSCP on Windows, FileZilla on Linux, Cyberduck or FileZilla on Mac, and an FTPS client on another phone.

Typical uses

- Copy files between a phone and a laptop on the same Wi-Fi.
- Open phone files from a desktop file manager.
- Hand someone a read-only login when they should download files and nothing else.

What this FTP server is not

It does not upload your files to the developer or to a cloud service. It is also not a public file host. Use it on a network you trust, such as home or office Wi-Fi.

FTPS Server is open source (CC0-1.0) and contains no ads.
