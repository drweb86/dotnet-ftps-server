<p>FTPS (FTP поверх TLS) сервер для безопасного обмена файлами между устройствами по сети.</p>
<p><b>Возможности:</b></p>
<ul><li><b>Права пользователей</b> - Гибкое управление операциями чтения и записи</li><li><b>Корневые папки для каждого пользователя</b> - Изолированные каталоги для каждого пользователя</li><li><b>Безопасность путей</b> - Защита от атак с обходом каталогов</li><li><b>UTF-8</b> - Поддержка локализованных символов</li><li><b>Самоподписанные сертификаты</b> - Автоматическая генерация TLS-сертификатов или использование своих</li></ul>
<p>Это приложение для Android (Kotlin). Без рекламы. Открытый код (CC0). Каждый пользователь выбирает папку системным диалогом. Уведомление держит передачи активными при выключенном экране.</p>
<p>Требуется Android 6.0 или новее.</p>
