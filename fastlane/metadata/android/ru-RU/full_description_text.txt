FTPS (FTP поверх TLS) сервер для безопасного обмена файлами между устройствами по сети.

Возможности:

- Права пользователей - Гибкое управление операциями чтения и записи
- Корневые папки для каждого пользователя - Изолированные каталоги для каждого пользователя
- Безопасность путей - Защита от атак с обходом каталогов
- UTF-8 - Поддержка локализованных символов
- Самоподписанные сертификаты - Автоматическая генерация TLS-сертификатов или использование своих
