<p>FTPS Server က ဖုန်း သို့မဟုတ် တက်ဘလက်ကို သီးသန့်ဖိုင်မျှဝေရန် လုံခြုံသော FTP ဆာဗာလုပ်သည်။ ဓာတ်ပုံ၊ ဗီဒီယို၊ စာရွက်စာတမ်းကို ကလောက်မတင်ဘဲ Wi-Fi တူရာ ကွန်ပျူတာနှင့် မျှဝေပါ။ ဘယ်သူချိတ်နိုင်သည်၊ ဘယ်ဖိုလ်ဒါဖွင့်နိုင်သည်၊ ဒေါင်းလုဒ်သာလော ပြင်နိုင်သေးလော သင်ရွေးသည်။</p>
<p><b>ကွန်ရက်ပေါ်တွင် ဖိုင်မျှဝေပါ၊ ကလောက်မှ မဟုတ်ပါ</b></p>
<p>ဖိုင်များသည် Android စက်ပေါ်တွင် ကျန်သည်။ အခြားစက်က ဤ FTP ဆာဗာသို့ သင့်ကွန်ရက်မှ ချိတ်သောကြောင့် မိတ္တူသည် သူတစ်ပါး သိုလှောင်မှုပေါ်တွင် မရှိပါ။</p>
<ul><li>ဓာတ်ပုံ၊ ဗီဒီယို၊ စာရွက်စာတမ်းကို ဖုန်းမှ PC သို့၊ PC မှ ဖုန်းသို့ ရွှေ့ပါ။</li><li>ကိုယ်ရေးနှင့် အလုပ်ဖိုင်ကို ပြင်ပအဖွဲ့၏ ကလောက်သိုလှောင်မှုအပြင် ထားပါ။</li><li>အိမ်၊ ရုံး၊ သို့မဟုတ် သင်ထိန်းသော ဟော့စပေါ့တွင် သုံးပါ။ ကလိုင်းယင့်သည် ကွန်ရက်တူတွင် ရှိရမည်။ Wi-Fi တူ၊ ဟော့စပေါ့တူ၊ သို့မဟုတ် USB ကွန်ရက်မျှဝေချိတ်။</li><li>မျက်နှာပြင်ပိတ်လျက် ဆာဗာဖွင့်ထားပါ။ အကြောင်းကြားချက်က လွှဲပြောင်းမှုဆက်လုပ်သည်။</li></ul>
<p><b>ဘယ်သူ ဘယ်ဖိုလ်ဒါဖွင့်နိုင်သည် ရွေးပါ</b></p>
<p>လူ သို့မဟုတ် စက်တိုင်းအတွက် လော့ဂ်အင်သီးခြားထည့်ပြီး လုပ်နိုင်သည်ကို ကန့်သတ်ပါ။</p>
<ul><li>ချိတ်ဆက်မှုတိုင်းအတွက် အသုံးပြုသူအမည်နှင့် စကားဝှက်လုပ်ပါ။</li><li>လော့ဂ်အင်တိုင်းကို ကိုယ်ပိုင်ဖိုလ်ဒါပေးပါ။ စက်ပေါ်ရှိ ကျန်ဖိုင်များကို ကြည့်၍မရပါ။</li><li>အပြည့်အဝခွင့် သို့မဟုတ် ဖတ်ရန်သာ လော့ဂ်အင်ပေးပါ။ ဖတ်ရန်သာသည် ဒေါင်းလုဒ်လုပ်နိုင်ပြီး အပ်လုဒ်၊ အမည်ပြောင်း၊ ဖျက်၍မရပါ။</li><li>အခြားစက်အသင့်ဖြစ်လျှင် လိပ်စာ၊ ပို့တ်၊ လော့ဂ်အင်ကို ကူးပါ သို့မဟုတ် မျှဝေပါ။</li></ul>
<p><b>ကုဒ်ဝှက်လွှဲပြောင်းမှု၊ ရိုးရိုး FTP မဟုတ်ပါ</b></p>
<p>ဤသည် FTPS ဆာဗာဖြစ်သည်။ explicit FTP over TLS (AUTH TLS)။ ကုဒ်ဝှက်မရှိသော ရိုးရိုး FTP ကို မသုံးပါ။ စကားဝှက်နှင့် ဖိုင်သည် ကွန်ရက်ဖြတ်စဉ် ကုဒ်ဝှက်သည်။</p>
<ul><li>လော့ဂ်အင်ကို ပွင့်လင်းမပို့ပါ။ လွှဲပြောင်းမှုက FTP over TLS သုံးသည်။</li><li>ပထမစတင်မှုက TLS လက်မှတ်ဖန်တီးပေးသဖြင့် အပိုပြင်ဆင်မှုမလိုဘဲ ချိတ်နိုင်သည်။</li><li>လက်မှတ်ရှိပြီးသားဆိုလျှင် ထိုလက်မှတ်ကို သုံးပါ။</li><li>အက်ပ်နှင့် ကလိုင်းယင့်ရှိ လက်မှတ်လက်ဗွေကို နှိုင်းပါ၊ ဤစက်သို့ ရောက်ကြောင်းသိရန်။</li><li>ဖိုင်အမည်ကို ကိုယ်ပိုင်ဘာသာဖြင့် ထိန်းသည်၊ အင်္ဂလိပ်အက္ခရာပြင်ပ စာလုံးများပါ။</li></ul>
<p><b>ဆာဗာဘာလုပ်နေသည် ကြည့်ပါ</b></p>
<ul><li>အက်ပ်က ကလိုင်းယင့်ထည့်ရမည့် လိပ်စာနှင့် ပို့တ်ကို ပြသည်။</li><li>လော့ဂ်အင်တိုင်းကို ဖိုလ်ဒါနှင့် ဖတ်ရန်သာ သို့မဟုတ် အပြည့်အဝဟု စာရင်းပြသည်။</li><li>တစ်ခုခုမအောင်လျှင် မှတ်တမ်းက ချိတ်ဆက်မှုနှင့် အကြောင်းရင်းကို ပြသည်။</li><li>ပို့တ်နှင့် တစ်ပြိုင်နက်ချိတ်နိုင်သော ကလိုင်းယင့်အရေအတွက်ကို သင်ရွေးသည်။</li></ul>
<p><b>FTP ဆာဗာကို အဆင့်လေးဆင့်ဖြင့် စပါ</b></p>
<p>1. အသုံးပြုသူအမည်၊ စကားဝှက်နှင့် အသုံးပြုသူထည့်ပါ။<br>2. ထိုအသုံးပြုသူဖွင့်နိုင်သော ဖိုလ်ဒါရွေးပါ။<br>3. ဖတ်ရန်သာ သို့မဟုတ် အပြည့်အဝခွင့် ရွေးပါ။<br>4. အခြားစက်တွင် FTPS ကလိုင်းယင့်ဖွင့်ပါ၊ explicit TLS (AUTH TLS) ဖွင့်ပါ၊ လိပ်စာ၊ ပို့တ်၊ လော့ဂ်အင်ထည့်ပါ။</p>
<p><b>ချိတ်နိုင်သော ကလိုင်းယင့်များ</b></p>
<p>explicit FTPS ပံ့ပိုးသော ကလိုင်းယင့်တိုင်း အလုပ်လုပ်သည်။ ဥပမာ။ Windows တွင် FileZilla နှင့် WinSCP၊ Linux တွင် FileZilla၊ Mac တွင် Cyberduck သို့မဟုတ် FileZilla၊ အခြားဖုန်းတွင် FTPS ကလိုင်းယင့်။</p>
<p><b>ပုံမှန်အသုံးများ</b></p>
<ul><li>Wi-Fi တူရာ ဖုန်းနှင့် လက်ပ်တော့အကြား ဖိုင်ကူးပါ။</li><li>ဖုန်းဖိုင်ကို ဒက်စ်တော့ ဖိုင်မန်နေဂျာမှ ဖွင့်ပါ။</li><li>ဒေါင်းလုဒ်သာလုပ်သင့်လျှင် ဖတ်ရန်သာ လော့ဂ်အင်ပေးပါ။</li></ul>
<p><b>ဤ FTP ဆာဗာ မဟုတ်သည်</b></p>
<p>ဖိုင်ကို ဆော့ဖ်ဝဲရေးသူ သို့မဟုတ် ကလောက်ဝန်ဆောင်မှုသို့ မတင်ပါ။ အများသုံးဖိုင်လက်ခံရာ မဟုတ်ပါ။ ယုံကြည်သောကွန်ရက်တွင် သုံးပါ၊ အိမ် သို့မဟုတ် ရုံး Wi-Fi ကဲ့သို့။</p>
<p>FTPS Server သည် ပွင့်လင်းရင်းမြစ် (CC0-1.0) ဖြစ်ပြီး ကြော်ငြာမရှိပါ။</p>
